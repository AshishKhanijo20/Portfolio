## The problem

IT service desks sit on a goldmine of structured ticket data, yet most AI assistants treat each conversation as if it started from scratch. Context gets lost between interactions, and every follow-up costs another round of expensive API calls.

## Approach

- Designed a **data-driven service desk** that combines structured ticket records with a **stateful generative AI assistant**.
- Implemented **persistent conversational memory** using ticket-linked dialogue threads, so the assistant can reason across interactions on the same issue.
- Exploring **tool-augmented LLMs** and **human-in-the-loop** workflows for actions that need approval.
- Investigating ways to **reduce API calls and token usage** without losing answer quality.

## Stack

FastAPI · SQLModel · PostgreSQL · Python · LLM APIs
